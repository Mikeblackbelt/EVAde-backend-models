# Space Radiation Data Sources

Access terms change; confirm each before use. Status: **VERIFIED** = checked on the source page or a bibliographic record; **PARTIAL** = from search summaries or release notes; **UNVERIFIED** = not confirmed.

## MSL RAD (Curiosity rover): PDS Planetary Plasma Interactions node
- **What:** energetic particle and dose measurements on the Mars surface. Calibrated data set MSL-M-RAD-3-RDR-V1.0 at pds-ppi.igpp.ucla.edu (PDS3 format). A dataset list showed Release 20 (2019); later releases not confirmed.
- **Access:** PDS data are public; no license statement was found in the retrieved pages (UNVERIFIED).
- **Use:** an external benchmark for dose-rate estimation and an example of calibrated particle data. **Limit:** Mars surface, not in-cabin.

## LRO CRaTER: PDS PPI node
- **What:** lunar radiation dosimeter. PDS4 bundle urn:nasa:pds:lro.crater (calibrated and derived data; raw EDR may remain in the PDS3 archive); release notes dated into 2026 (dates inconsistent in search summaries; PARTIAL).
- **Access:** data.gov catalog entries list "restricted public" access with no license. Check PDS terms before redistribution.

## NASA OSDR RadLab
- **What:** web GUI plus API for ISS radiation detector data (DORELI detectors, Liulin-5) with absorbed dose rate, flux, and dose equivalent where available. A May 2026 NASA data highlight reports Artemis I radiation telemetry added (PARTIAL; portal not opened).
- **Access:** visualization.osdr.nasa.gov/radlab; license and bulk terms not confirmed. A 2025 report mentions controlled-access features for some OSDR data (secondary, UNVERIFIED).

## DOSIS 3D (DLR) and published tables
- **What:** ISS Columbus dose measurements. Open-access papers (Berger 2016, 2017) publish tables for benchmarking transport codes.
- **Access:** no public raw-data download portal was found (UNVERIFIED); contact DLR.

## Agency technical reports
- NASA-STD-3001 Vol. 1 and the NASA OCHMO radiation technical brief (public). NCRP Report 183 (CNS effects, 2019) and ICRP Publication 123 are cited in the radiation section; their text was not read.

## Ground calibration
- Lab sources (Sr-90, Cs-137) calibrate electronics only. Heavy-ion calibration needs beam facilities (HIMAC, NSRL, GSI) by proposal; no open data. Lab sources need institutional radiation-safety approval.

## Notes
- Record the calibration version with every dataset; do not assume a reading from one location applies elsewhere in a vehicle (Artemis I showed about fourfold spatial variation).
